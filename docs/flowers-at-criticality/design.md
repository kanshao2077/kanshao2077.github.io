# 展览页面

2026-10-15，根据用户反馈修订。

## 空间

页面以白色展墙为基本空间，灰黑文字、大量留白，作品图独立陈列。保留黑色影棚作品图的原始色彩，界面移除黄色与金色。标题以汇文明朝体为主，拉丁辅助信息使用简洁无衬线字。

## 顺序

入口作品、引言、八件作品、短命题、时间实验、五层理念、形态研究、结束作品。

## 字体

采用汇文明朝体真实 WOFF2 文件，按本页面所需字符自托管 52 个分片。浏览器实际字体检查通过。字体来源和 Public Domain 元数据保留在 `assets/fonts/NOTICE.txt`，不依赖在线字体服务加载。
