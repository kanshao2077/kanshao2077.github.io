# 本项目的极简阅读规范

方向：暖纸白、炭黑和少量灰阶。让内容、字号与留白建立层级。照片保留本身颜色，UI 不再加入绿色或其他装饰性色。

参考并转化规则，未直接安装这些设计系统或照搬品牌：

- [Vercel Geist Colors](https://vercel.com/geist/colors)：背景、边框、次要文字、主要文字分工明确；默认使用灰阶。
- [Vercel Geist Typography](https://vercel.com/geist/typography)：标题、标签与长篇正文使用不同字号和行高。
- [Radix Themes Color](https://www.radix-ui.com/themes/docs/theme/color)：灰阶与主题角色分开，浅色/深色保持一致语义。
- [USWDS Using type](https://designsystem.digital.gov/design-tokens/typesetting/overview/)：阅读体验同时取决于字形、字号、行高和行长。

## 色彩角色

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 页面 | `#FAF9F6` | `#171717` | 阅读背景 |
| 表面 | `#FFFFFF` | `#202020` | 弹窗、练习与图表 |
| 正文 | `#202020` | `#F3F2EC` | 主文字与标题 |
| 次要文字 | `#60605C` | `#B5B4AE` | 导语和辅助说明 |
| 辅助文字 | `#71716B` | `#A09F99` | 日期、标签与元数据 |
| 细线 | `#E4E2DC` | `#3D3C39` | 分隔和容器边界 |
| 交互 | `#282828` | `#ECEBE5` | 主按钮、链接、选中与焦点 |
| 轻底色 | `#F0EFEB` | `#2B2B29` | 提示、选中与悬停背景 |

使用 CSS 变量维护语义，避免在组件中不断追加新颜色。按钮有悬停反馈、键盘焦点有轮廓；完成状态同时使用文字和标记，不仅依赖颜色。

## 排版与版面

- 中文优先使用系统苹方，回退到 Noto Sans SC / Microsoft YaHei / sans-serif，减少外部字体加载。
- 英文展示文字使用 Georgia；日期、序号和标签使用系统等宽字。
- 正文桌面16px，手机14px，行高1.95。正文段落限制到46em。
- 主内容最大850px，桌面保留侧边目录；800px以内改为抽屉目录。
- 细线为1px，圆角以3–5px为主。阴影主要用于弹窗。
- 320 / 390 / 768 / 1024 / 1440px检查页面溢出。表格可在自身容器横向滚动。
- 支持深色模式、减少动态效果、键盘导航和跳到正文。

这份规范是适合中文课程的项目调整，不声称完整符合任何第三方设计系统或通过全面 WCAG 认证。
