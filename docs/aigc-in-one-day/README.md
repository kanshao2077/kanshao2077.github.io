# 一天内成为 AIGC 专家

侃少的免费中文创作学习手册。采用纸白、炭黑与灰阶的极简阅读界面，包含12个核心制作章节与3个行业拓展章节。

## 内容

- 概念、历史、模型、提示词、图像、连续性、分镜、视频、声音、工作流、验收与项目练习。
- 27个国内外代表性平台入口，可按地区和任务筛选。
- 41个术语的解释与实例。
- 市场数据区分统计时间、地区、月活、访问量、使用时长与消费支出。核查日期：2026-10-14。
- 白模、多模态参考、运动参考、原生音视频、定向编辑、世界模型与制作流程。
- 浏览器保存学习进度、练习勾选与笔记；笔记可导出 Markdown。

标题表达的是一天的集中学习路线。长期专业能力来自作品实践与复盘。课程中的时间是练习预算，实际工具生成和返修可能更久。

## 本地预览

这是无需构建的静态网站，不需要安装前端依赖。在此目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。也可以直接打开 `index.html`，但剪贴板等功能在本地 HTTP 服务中更可靠。

```sh
npm run check
```

## GitHub Pages

部署使用现有仓库 `kanshao2077/kanshao2077.github.io` 的独立目录：

- 发布文件：`public/aigc-in-one-day/`
- 资料与验证：`docs/aigc-in-one-day/`
- 目标地址：`https://www.kanshao2077.cn/aigc-in-one-day/`

使用 GitHub CLI 提交并触发现有 Pages 工作流；实际部署结果以仓库 Actions 和线上访问检查为准。

现有 Astro 构建复制 public 文件，复用原仓库的 GitHub Pages 自动发布流程。只增加课程目录，不修改个人站主页。静态资源为相对路径，支持子目录访问。

本地 `.github/workflows/pages.yml` 是将来迁移到独立静态仓库时的发布配置，不上传到现有个人站以避免重复工作流。

## 维护

- `course.js`：核心课程、术语、测验、论文资料。
- `industry.js`：平台、市场快照、新技术及资料。
- `app.js`：导航、搜索、弹窗、练习、进度与笔记。
- `styles.css`：浅色/深色及响应式样式。
- `docs/design-system.md`：本项目设计规则和参考规范。
- `docs/research-notes.md`：市场数据口径与技术可用性说明。

学习记录仅存当前浏览器，没有账户同步。模板练习不调用生成 API。网站没有后端、收费流程或分析追踪。

中文内容与界面为本项目重新制作；学习结构参考 [Ben’s Bites](https://cookbook.bensbites.com/cookbook/become-technical-in-1-day/)。演示图片为 AI 生成，白模图是教学示意，不作为产品效果证明。未复制原站标志、商业课程正文或品牌资产。
